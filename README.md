# CartApp — React & Redux E-Commerce Store

A modern, responsive shopping cart web application built with **React** and **Redux Toolkit**. It fetches product data dynamically from an external REST API and manages global cart state seamlessly across routes.

🔗 **Live Demo:** https://react-app-ivory-nu.vercel.app/

---

##  Features

- **Dynamic Product Catalog:** Fetches and displays products cleanly in a responsive grid layout.
- **Global State Management:** Powered by **Redux Toolkit** to synchronize cart items and the navbar cart counter in real time.
- **Full Cart Operations:**
  - Add products to the cart with automatic quantity tracking for duplicate items.
  - Remove individual items or clear the entire cart with a single click.
  - Real-time total cost calculation formatted to two decimal places.
- **Client-Side Routing:** Smooth navigation between the Storefront (`/`) and Cart (`/Cart`) views using **React Router**.

---

##  Tech Stack

- **Frontend:** React.js, React Router DOM
- **State Management:** Redux Toolkit (`@reduxjs/toolkit`, `react-redux`)
- **Styling:** Bootstrap 5, Custom CSS
- **API:** FakeStore REST API
- **Deployment:** Vercel
